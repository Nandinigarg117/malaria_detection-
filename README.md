# 🦠 Malaria Detection Using CNN with Grad-CAM

## Overview

A deep learning project to detect malaria-infected cells from microscopic blood smear images using a **Convolutional Neural Network (CNN)**. The model is enhanced with **Grad-CAM** to provide visual explanations by highlighting regions responsible for predictions.

---

## Objectives

* Classify cell images as **Parasitized** or **Uninfected**
* Improve model interpretability using Grad-CAM
* Support early and accurate malaria diagnosis

---

## Model Details

* Architecture: CNN
* Task: Binary Classification
* Visualization: Grad-CAM heatmaps
* Evaluation Metrics: Accuracy, Precision, Recall, F1-score

---

## Dataset

* Public malaria cell image dataset (e.g., NIH dataset)
* Contains labeled images of infected and healthy cells

---
